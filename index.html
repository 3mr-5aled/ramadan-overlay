🌙 ramadan-overlay

Add beautiful Ramadan and Eid celebration overlays to any website in seconds. Auto-detects Ramadan, Eid Al-Fitr, and Eid Al-Adha dates, dedicated visual variants, and works with every major framework — zero dependencies.

npm install ramadan-overlay
React Vue Angular Svelte Vanilla JS CDN
Try the configurator ↓ View on GitHub ↗
🗓️
Auto-detection
Automatically activates during Ramadan, Eid Al-Fitr, and Eid Al-Adha using Hijri calendar calculation — no manual dates needed.
🎨
8 Variants
Lanterns, Sparkles, Crescent & Stars, Geometric, Eid Al-Fitr, Eid Al-Adha, and Banner styles to suit any site.
⚡
Lightweight
Zero runtime dependencies, tree-shakeable, and works with any front-end stack or plain HTML.
🌍
Region-aware
Supports 10+ regional Ramadan start-date calendars with a configurable Hijri offset.
